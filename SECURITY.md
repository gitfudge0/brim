# Security Policy

## Supported Versions

Security fixes are provided on a best-effort basis for the current main branch
and the latest repository state.

## Reporting A Vulnerability

Do not open public issues for security vulnerabilities.

If GitHub private vulnerability reporting is enabled for this repository, use
that first. Otherwise, email the maintainer privately at
mahapatra.digvijay@gmail.com.

When reporting an issue, include:

- The affected command, provider, or workflow
- Reproduction steps
- Expected behavior and actual behavior
- Relevant logs or command output with secrets redacted
- Any notes about tokens, auth files, keyring usage, or local environment

Please avoid disclosing details publicly until the issue has been reviewed and
fixed or mitigated.
